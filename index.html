02 / Active Learning & Hardening

Securing the nervous system of autonomous machines.

Robots are distributed computing clusters on wheels and legs. In production environments, an unauthenticated topic, unencrypted DDS channel, or spoofed sensor frame is a direct physical hazard. Here is how I am expanding into robotics cybersecurity, ethical hacking, and transport defense.

Cryptographic Access • Middleware

SROS 2 & DDS Transport Security

Configuring SROS 2 keystores, PKI certificate authorities, and S/MIME topic encryption across CycloneDDS and FastDDS. Enforcing strict XML governance policies so rogue nodes cannot subscribe to sensitive camera feeds or publish unauthorized /cmd_vel actuator commands.

SROS 2 DDS Security Plugins PKI Governance Topic Access Control Encrypted Telemetry
Zero-Trust Boundaries • Network

Network Isolation & Telemetry Integrity

Defending against lateral network compromise. Implementing iptables and nftables firewalls on Ubuntu Linux, dedicated VLAN isolation for perception LIDARs versus motor controllers, and mutual TLS (mTLS) for remote fleet management.

VLAN Segmentation Linux nftables mTLS Fleet Gateways Socket Hardening
Integrity • Threat Mitigation

Rogue Node Injection & Replay Mitigation

Preventing unauthorized ROS 2 node discovery on open local networks through ROS_DOMAIN_ID isolation, topic whitelisting, and cryptographic signing on time-critical sensor streams to prevent physical actuation hijack.

Rogue Node Defense ROS_DOMAIN_ID Replay Attack Prevention Sensor Signature Checks
Hardware Defense • Silicon Edge

Embedded Firmware & Hardware Root of Trust

Securing the edge: secure boot validation on ESP32 microcontrollers, encrypted non-volatile storage (NVS) for credentials, signed firmware OTA updates, and CAN bus monitoring to prevent bus-injection attacks on motor drivers.

ESP32 Secure Boot NVS Flash Encryption Signed Firmware OTA CAN Bus Integrity
