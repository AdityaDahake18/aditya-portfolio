# Asset Credits & Open Source Attributions

This project utilizes openly licensed 3D models, textures, and open-source libraries.

## 1. 3D Humanoid Robot Models
- **Unitree G1 Humanoid Model (`assets/models/unitree_g1.glb`)**
  - **Source:** Unitree Robotics Open Robot Model / `zhiyangrobot/g1-ffmaster-retarget`
  - **License:** Apache 2.0 / Open Source Research License
  - **Description:** Complete kinematic mesh representation of the Unitree G1 humanoid robot, featuring multi-link torso, head, bipedal legs, and articulated arms.
- **Xbot Humanoid Robot Model (`assets/models/xbot.glb`)**
  - **Source:** Three.js Examples Repository (`mrdoob/three.js`)
  - **License:** MIT License (Copyright © 2010-2024 Three.js Authors)
  - **Description:** Rigged humanoid robotic character model optimized for real-time web rendering under 3MB.
